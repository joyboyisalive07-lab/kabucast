# kabucast

A turnip price predictor for Animal Crossing: New Horizons. Given the Sunday
buy price and whatever half-day prices are known so far, it returns a posterior
probability for each price pattern, the plausible price paths, and a decision
about when to sell.

The project is under construction. This file is replaced by the full README,
alongside a Russian translation, before the first release.
